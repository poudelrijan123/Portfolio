IMPLEMENTED IN THIS PRO BUILD

- Clicking the RIJAN wordmark returns to the welcome homepage.
- Interactive monochrome/colour comparison slider using the existing mountain-road photograph. The comparison is clearly labelled as a visual demo, not a RAW-grade claim.

- Form constraints, responsive layout, keyboard focus styles and reduced-motion support retained.

DEPLOYMENT NOTES
- Deploy the contents of this folder to Netlify (not the enclosing folder containing another nested project folder).
- Netlify Forms must be enabled for the site. After deployment, submit a real test inquiry and verify it appears under Forms in the Netlify dashboard.
- The form does not upload files; visitors can provide a shareable reference URL.
- Three.js is loaded from jsDelivr at runtime. The camera has a static fallback if the CDN is unavailable.
- Webcam preview requires HTTPS and explicit visitor permission; it is not automatically activated.

VERIFICATION STATUS

- This environment cannot certify the user's live Netlify configuration, real device rendering, webcam permissions, or successful form receipt. Complete the deployment checks in README before describing those as verified.
